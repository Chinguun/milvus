# CBO Customization Demonstration

This script demonstrates the Cost-Based Optimizer (CBO) customization in Milvus by creating sample data, executing queries with different filter expressions, and displaying CBO evaluation results.

## Prerequisites

1. Milvus must be running and accessible
2. CBO evaluation must be enabled (default: `proxy.cbo.evaluation.enabled=true`)
3. Python 3.7+ with required packages

## Installation

Install required Python packages:

```bash
pip install -r scripts/cbo_demo_requirements.txt
```

Or install individually:

```bash
pip install pymilvus requests numpy
```

## Usage

### Basic Usage

Run the demo script with default settings:

```bash
python3 scripts/cbo_demo.py
```

### Running Inside Docker Container

If Milvus is running in a container and you want to run the script from the builder container:

```bash
docker exec milvus-builder-1 bash -c "cd /go/src/github.com/milvus-io/milvus && python3 scripts/cbo_demo.py"
```

### Command Line Options

```bash
python3 scripts/cbo_demo.py [OPTIONS]

Options:
  --host HOST           Milvus host (default: 127.0.0.1)
  --port PORT           Milvus port (default: 19530)
  --http-port PORT      Milvus HTTP port (default: 9091)
  --collection NAME     Collection name (default: cbo_demo_collection)
  --num-vectors N       Number of vectors to insert (default: 100000)
  --keep-collection     Keep existing collection if it exists
```

### Examples

Run with custom host and port:

```bash
python3 scripts/cbo_demo.py --host 192.168.1.100 --port 19530
```

Run with smaller dataset for faster testing:

```bash
python3 scripts/cbo_demo.py --num-vectors 10000
```

Keep existing collection:

```bash
python3 scripts/cbo_demo.py --keep-collection
```

## What the Script Does

1. **Checks Milvus Readiness**: Verifies Milvus is running and accessible via HTTP and pymilvus
2. **Creates Collection**: Sets up a collection with:
   - Primary key field (int64, auto-id)
   - Vector field (128-dim float vector)
   - Scalar fields: `price` (float), `category` (int64), `rating` (float)
3. **Inserts Data**: Generates and inserts 100,000+ vectors with varied distributions:
   - Price: Uniform distribution [0, 1000]
   - Category: 10 distinct categories
   - Rating: Normal distribution around 4.0
4. **Creates Index**: Builds IVF_FLAT index on vector field
5. **Executes Queries**: Runs multiple search queries with different filter expressions:
   - High selectivity queries (should use standard filtering)
   - Low selectivity queries (should use iterative filtering)
   - Range queries
   - Combined filters
6. **Displays Results**: Shows CBO evaluation metrics including:
   - Individual query metrics (selectivity, strategy, execution time)
   - Aggregated evaluation summary
   - Performance comparison
   - Optimization recommendations

## Expected Output

The script will display:
- Milvus readiness status
- Collection creation and data insertion progress
- Query execution results
- CBO metrics for each query
- Aggregated statistics
- Performance comparisons
- Optimization recommendations

## Troubleshooting

### No CBO Metrics Found

If you see "No CBO metrics found", ensure:
- CBO evaluation is enabled: `proxy.cbo.evaluation.enabled=true`
- Queries have been executed successfully
- Milvus proxy HTTP endpoint is accessible on port 9091 (or your configured port)

### Connection Errors

If you get connection errors:
- Verify Milvus is running: `curl http://localhost:9091/healthz`
- Check host and port settings match your Milvus configuration
- Ensure network connectivity between script and Milvus

### Collection Already Exists

If the collection already exists, either:
- Use `--keep-collection` to keep it
- Or drop it manually: `utility.drop_collection("cbo_demo_collection")`

## Notes

- The script uses the mock selectivity estimator by default
- To use statistics-based estimator, configure: `proxy.cbo.useStatisticsEstimator=true`
- Collection ID is automatically determined from CBO metrics
- Query IDs are generated by the CBO system
